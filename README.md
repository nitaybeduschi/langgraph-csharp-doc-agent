# LangGraph C# Documentation Agent

Agente inteligente desenvolvido com **LangGraph** para automatizar a geração de documentação técnica de código C#.

## Objetivo

Este projeto foi desenvolvido como mini projeto avaliativo da disciplina de Agentes com IA.

O agente recebe um arquivo `.cs`, analisa sua estrutura e gera uma documentação técnica organizada, auxiliando equipes de desenvolvimento na criação e manutenção de documentação de software.

## Funcionalidades (Roadmap)

- [ ] Leitura de arquivos C#
- [ ] Extração de informações da classe
- [ ] Geração automática de documentação
- [ ] Exportação em Markdown
- [ ] Memória utilizando LangGraph
- [ ] Uso de ferramentas (Tools)
- [ ] Fluxo baseado em State Graph

## Tecnologias

- Python
- LangGraph
- LangChain
- OpenAI API
- Markdown
